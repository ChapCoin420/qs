# Integrations

All external services sit behind ports (interfaces) in `modules/integrations/`, with a fake
implementation for tests and local development.

| Integration                                                 | Phase                     | Purpose                                           | Notes                                                                                                                                                                                                                                                                                                                                                                                                                               |
| ----------------------------------------------------------- | ------------------------- | ------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **WhatsApp Business Platform (Cloud API, Meta)**            | 3 (reminders in 2)        | Receptionist, reminders, waitlist offers, OTP     | Requires Meta Business verification, a dedicated number, approved Hebrew templates. Free-form replies only inside the 24 h customer-service window; outside it, templates (utility / marketing / authentication — priced differently). Webhooks signed with app secret. Business-specific bots only (general-purpose AI assistants barred since 15 Jan 2026). Marketing messages need opt-in per WhatsApp policy _and_ Israeli law. |
| **Claude API (Anthropic)**                                  | 3                         | Hebrew understanding, tool use                    | Tool-use loop server-side; model tier chosen by Hebrew eval (quality vs latency/cost); prompt versioning; zero data used beyond the request; DPA review.                                                                                                                                                                                                                                                                            |
